讓討論自動回到這裡

由 GitHub Actions 每 3 小時同步 milin-chang 的 Discussions。

  1. 加入讀取用 Token

    在專案的 Actions Secrets 新增 DISCUSSIONS_TOKEN。Token 需要能讀取你想彙整的私人 repo 的 Discussions。

    開啟 Actions Secrets
  2. 啟用 GitHub Pages

    在 Settings → Pages，把 Source 選為 GitHub Actions。

    開啟 Pages 設定
  3. 執行第一次同步

    進入 Actions → Update discussion dashboard，按下 Run workflow。之後就會定時更新。

    開啟同步工作流程
